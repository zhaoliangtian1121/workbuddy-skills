# 证据审计与假设证伪

## 目的

把一个「看起来成立」的判断拆成可被数据推翻的命题，验证到可复核，再决定要不要说出口。本技能同时管住两件事：验证方法是否足以支撑结论，以及结论输出前的机械性错误。

## 适用与不适用

适用：给出任何带数字、带判定、带文件的结论之前；评估一个机会、策略或方案是否值得做；复核他人的统计结论；结论被新数据推翻后找根因；错误流水复盘。

不适用：纯概念解释、闲聊、无判定无数字的叙述。这类场合跳过全部流程。

## 四条硬原则

1. **先写失效条件，再算收益。** 在动笔算期望值之前，写出「什么数据出现就证明这个主张错了」。写不出失效条件的主张，直接放弃评估。
2. **优先怀疑输入，再怀疑公式。** 新证据与旧结论冲突时，先核对取数口径、数据源、字段同步性，再检查计算式。公式正确但输入错，是本技能记录过的翻案主因。
3. **把摩擦算进结论。** 收益率必须写明毛利还是净利；成本包含手续费、点差、滑点与时间成本。只报毛利的收益数字一律不输出。
4. **对无法查证的内容直说不知道。** 状态码含义、平台内部参数、未公开费率，没有一手证据就标注「不知道」，不用常识补全。

## 六步流程

### 第 1 步 拆命题

把模糊主张写成编号条件列表，逐条标「已验证 / 未验证 / 不适用」。存在「未验证」条目时，禁止输出结论，先补验证。

示例：把「这笔可做」拆成 ①时效窗口 ②模型概率 ③落箱规则 ④报价字段非空 ⑤净 EV 达标。五条缺一不可，只跑两条就下结论属于 E1。

### 第 2 步 锁口径

记录四件事：数据源文件与路径、字段含义、阈值从哪个文件的哪一行读出、取数时刻是否同步。禁止凭记忆写阈值。字段来自不同时刻快照时，改用同一时刻的一手数据重取。

### 第 3 步 设计推翻性检验

按主张类型选检验，至少选一种能把它证伪的：

| 主张类型 | 首选检验 | 最低要求 |
|---|---|---|
| 预测因子有效 | 时间外验证 + 对基线做残差化 | 按时间切分训练集与测试集，禁止随机切；报告样本外指标 |
| 报价类机会 | 存续检验 | 同时报出现率与存续时长，缺一不得算收益 |
| 点差或价差类 | 同步取数对照 | 同一时刻、同一标的的买卖两侧，替代拼接快照字段 |
| 分组优势 | 全档位经济性分档 | 每档写 n、胜率、保本线、净 EV；禁止只报最好的一格 |
| 策略整体 | 摩擦归因 | 拆分定价误差与摩擦占比，说明优势在哪个成本结构下才兑现 |

常见陷阱：决策时刻之后才产生的信息不得入模（时间穿越）；多个分组里挑出一个显著正值属于多重比较；几个不同因子给出完全相同的指标值时，先按 bug 排查，不当巧合。

### 第 4 步 算之前先排雷

按 `references/failure-modes.md` 的 13 类逐项对照当前工作。重点检查：参数是否从文件读取、回归自变量与因变量位置、标签数据源是否与规则原文一致、结论改动后其它章节是否留残、失败路径是否被默认值静默兜底。

### 第 5 步 写结论

遵守 `references/self-check.md` 的书写规矩：每个数字带来源标签，「满足条件」附条件表，可复算的数字附脚本与参数。样本量小于 5 时禁用绝对词并写出 n。列出与结论相反但尚未排除的变量。

### 第 6 步 交付

逐项过八项自检，在末尾附一行自检回执。某项未做时写「未做 + 原因」，不省略、不假称全过。

## 自带资源

- `references/self-check.md`：八项自检的具体动作、三条书写规矩、回执格式与适用边界。出结论前必读。
- `references/failure-modes.md`：13 类失效模式的定义、触发条件、拦截动作，附 51 条真实错误流水的分布。排雷与复盘时读。
- `references/case-studies.md`：五个真实翻案案例，展示「错误结论 → 检验法 → 翻案证据」的完整链条。设计检验时读。
- `scripts/audit_errors.py`：统计错误流水的类型分布与复发次数。运行 `python scripts/audit_errors.py --path <errors.jsonl>`；复发达阈值的类型会单独列出，提示升级为强制脚本。

## 边界

本流程压的是机械错误，压不住判断错误——选哪个指标当证据、信哪个先验、何时算够，这类没有唯一解。最有效的外部校验是追问数字来源；被追问时优先给出中间量（判定表、失败原因分布、边界记录），而不是重复结论。
