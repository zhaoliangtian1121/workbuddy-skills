# 交付前八项自检

## 适用范围

每次输出结论、文件或数字之前逐项过一遍。纯闲聊与纯概念解释只需过第 1、5、6 项。本清单管的是机械错误（漏条件、参数靠记忆、改漏一处）；判断类错误不在覆盖范围内。

## 八项动作

| # | 检查目标 | 执行动作 | 不通过时 |
|---|---|---|---|
| 1 | 判定条件穷举 | 把「满足 X」里的 X 拆成编号条件列表，逐条标已跑、未跑、不适用 | 存在未跑项即停止输出，先补跑 |
| 2 | 数字来源标注 | 给每个数字加 `[实测 n=?]`、`[推断]`、`[待验]` 三者之一 | 补不出实测的改口为推断 |
| 3 | 阈值取自文件 | 凡出现具体阈值，回查配置键或源码行号，记录出处 | 凭记忆写的一律重读 |
| 4 | 边界记录回看 | 算出「N 条满足」后，打印最接近门槛的 1–3 条完整字段 | 字段自相矛盾时回到第 1 项重算条件 |
| 5 | 小样本禁绝对词 | 全文搜「唯一 / 必然 / 最好 / 一定 / 全部」；n<5 时一律改写为「存在一个例子」并写出 n | 引用历史原话可豁免，只查本次结论句 |
| 6 | 默认值兜底排查 | 检查代码里 `.get(k) or 默认值`、可空字段、缺省符号 | 统计该字段非空数与总数，显式报告 |
| 7 | 改一处不留残 | 改动某个结论后，全文搜被改概念的关键词，逐处核对 | 改完再搜一遍确认无残留 |
| 8 | 文件内部自洽 | 找成对约束（禁止 X 与允许 X、门槛 A 与参数 A、必填与可选） | 冲突处二选一，写明优先级 |

## 三条书写规矩

**规矩一：数字带标签。** 每个数字后面紧跟来源类别，并附样本量或推断依据。无法复算的数字标 `[推断]` 并说明依据，不得混入实测数字。

**规矩二：「满足条件」附条件表。** 不写「有 X 条可执行」，改写为编号条件列表 + 各条件命中数 + 最接近门槛那条的完整字段与差距值。

**规矩三：可复算数字附命令。** 凡「多少条 / 什么比例 / 中位数」这类，附能复现它的脚本名与参数。不能复算的明确改标推断。

## 回执格式

每次交付末尾附一行，缺项即视为未做：

```
[自检 v1.0] 1-8 全过 | 实测类脚本: <脚本名> <参数> | 边界回看: <记录号> | 来源标注 12/12 | 绝对词 0 处
```

某项未做时如实写明原因，例如：

```
[自检 v1.0] 4 未做（本机无对应数据文件，无法回看） | 其余过
```

禁止用「全过」掩盖未做项。

## 失效模式的升格规则

错误流水按类别汇总。同一类别复发达到 3 次时，把拦截动作从人工清单升级为强制脚本，不再依赖记忆执行。运行 `scripts/audit_errors.py` 取得当前分布。
